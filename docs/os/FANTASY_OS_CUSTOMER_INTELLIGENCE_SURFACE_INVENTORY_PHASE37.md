## Real, previously-undetected finding this phase

**`/dashboard` — the platform's actual primary landing page — hides the global top navigation entirely** (`app/dashboard/layout.tsx`'s `hideHeader` prop, with an explicit code comment: "Top-header functionality is wired into the dashboard's center button row... instead"). This means Phase 36's `/manager-hub` primary-nav fix, while real and correct, was **invisible from the one page most users see first**. `/commissioner-hub` already had its own dedicated in-shell entry (a `NavChip` in `DashboardHero.tsx`, plus a full contextual card for commissioners); `/manager-hub` had neither. Fixed this phase — see Dashboard Consolidation Report.

## Corrections to this phase's own brief

- NFL/NCAAF's league home dashboard does **not** currently render `LeaguePulseCard`/`ManagerDnaCard`/`DecisionRecommendationsCard` inline — its "Manager Intelligence"/"League Intelligence" sections are static, entitlement-gated marketing tiles with no live engine output. Only `UserOsCardConnected` and `ManagerReplayInsightsCard` are genuinely live on that page.
- "League Health" is computed by **three independent real engines** across three different real pages (`getCommissionerHubHealthForUser` on `/dashboard` and `/commissioner-hub`; the G15.6 Intelligence API on `/league/[leagueId]/intelligence`; Mission Control/League Analytics on `/commissioner-hub`), not one shared source — the single strongest consolidation candidate found this phase.
- Game Day OS (`lib/shared-services/game-day/`) confirmed still fully dead code — no live surface anywhere shows "Game Day cards" as such; Matchup Center is the only real live/matchup surface.
